# Brand marks for the panel's launchers

`github.svg` and `gitlab.svg` are the monochrome marks from [Simple Icons](https://simpleicons.org) (CC0 1.0),
unaltered. They are trademarks of GitHub, Inc. and GitLab Inc.; both companies' brand guidelines allow using the
mark as the icon of a link to one's project there, and forbid changing it (no recolouring into a Tango-style
drawing, no outlines, no effects). The panel paints them in the text colour through a CSS mask, which keeps the shape.

They belong to the website only. They are not part of the icon theme this project builds, and nothing under
`submodules/` or `dist/` includes them.
